One 1024×1024 front page for Monday 23 November 2026: the COP31 climate summit's collapse in Antalya leads 22 day-checked stories from 6 continents — 12 numbered panels, ten one-line briefs and a dotted world atlas (see SOURCES.md for the source list behind every item). The page is drawn by `render.py` from the story data in `stories.json`; `main.ts` delivers the finished `entry.png` to the grader.

## Run it

```sh
node main.ts
```

Copies `entry.png` into `$MAKEFUN_OUTPUT_DIR` (or `/output`). To rebuild the image itself: `python3 render.py` (needs Python 3 + Pillow).
